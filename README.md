# 茶记 Cha Ji

A personal Gong Fu Cha journal for tracking teas you've tried.

## Features

- Log teas with name, type, origin, vendor, and season
- Star ratings (1–5)
- Brew parameters: water temperature, tea/water ratio, first steep time
- Tasting notes and "buy again?" flag
- Search, filter by type/rating, and sort
- Data persisted to a local `teas.json` file

## Setup

```bash
npm install
npm start
```

Then open http://localhost:3333 in your browser.

## Keyboard shortcuts

- `n` — new tea entry
- `Esc` — close modal
